# Japfa Payload Platform Application

Next.js 15 App Router + Payload CMS v3 + PostgreSQL + Tailwind CSS.

## Setup

```bash
pnpm install
cp .env.example .env.local
# update .env.local with your values
pnpm payload migrate
pnpm local
```
